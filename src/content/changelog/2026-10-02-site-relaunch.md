The old single-page compatibility table is gone. Everything now has its own page and loads fast:

- **A page for every firmware file**, showing who publishes it (vendor sites, mirrors, or Wayback Machine copies), the retail models each vendor sells it as, version, release date, size, checksums and changelog.
- **Permanent downloads**: where a file has been archived on the Internet Archive, that copy is offered first, because vendor links break.
- **Clear warnings** on firmware that is truncated, can't be downloaded, or isn't Dahua firmware at all (some vendors also sell Hikvision-made devices).
- **Device pages** built from the hardware IDs inside the firmware, so you can find every compatible file, whichever brand published it.
- **Retail model and vendor pages**, with each vendor's current firmware listed first.
- **Search** for models, device IDs and file names, right from the header.
- **[Newly added](/new/)** firmware with an RSS feed, plus this changelog.

As before, flashing firmware is entirely at your own risk. See [why this site exists](/#why) before you start.
